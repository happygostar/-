# E지킴이 앱 — 안드로이드 · iOS 소스 (v1.0.0 파일럿)

사단법인 에너지안보환경협회 「E지킴이 앱개발 기획서 v1.0」(2026.10.22)과 인터랙티브 프로토타입을 그대로 옮긴 **스마트폰 앱 소스**입니다.
하나의 화면 코드(`www/`)를 Capacitor로 감싸 **안드로이드 앱(android/)** 과 **아이폰 앱(ios/)** 을 함께 만들고, 같은 코드를 **웹앱(PWA)** 으로도 배포할 수 있습니다 (기획서 4.1 "PWA 우선, 스토어는 나중" 전략).

---

## 1. 구현 범위 — 화면정의서 9화면 + 온보딩

| 화면 | 이 앱에서 실제로 동작하는 것 |
|---|---|
| 0. 온보딩 | 수료증 **QR 실시간 스캔**(카메라) · 사진으로 QR 인식 · 코드 직접 입력. 코드는 **SHA-256 해시로만 대조**(평문 미저장) |
| 0-1. 동의 | 이용약관·위치·사진·공익신고자 보호 **필수 동의 분리**, 알림 선택 동의, 동의 시각 기록 |
| 1. 홈 | 등급·신뢰점수·포인트·현금 전환 예정액, 수임 중/가능 케이스(현재 위치 기준 거리순), 최근 활동, 안전 수칙 |
| 2. 순찰 지도 | **실제 지도(OpenStreetMap)**, 시설 핀 상태색, **실시간 GPS 추적**, **50m 지오펜싱 알림**(진동+안내), 순찰 시간·거리 기록 → 지갑 L2 반영. 현장 밖 시험용 **위치 시뮬레이션** |
| 3. 카메라 자동점검 | **실제 카메라 촬영** + 증거(GPS·시각·해시) 기록. AI 판정은 **시범(데모) 판정**으로 명시 표시, 결과를 "AI 제안"으로 가져오며 **사람이 버튼을 눌러 확정해야 제출 가능** |
| 4. 케이스 보드 | 유형 필터, 수임 확인, 자율 제보는 매번 새 케이스 생성, 현상금 일부는 **시니어 이상만 수임** |
| 5. 점검 실행 | 체크리스트 v1(주유·충전 8 / 변전·발전 8 / 취약주택 6), 3단 판정, 항목별 **증거 사진 촬영**, 사진마다 GPS·시각·SHA-256. **미판정·AI 미확정·조치필요 항목 사진 누락 시 제출 차단** |
| 6. 신고 연계 | 신고서 자동 생성, 채널 선택(환경신문고 128 · 안전신문고 · 한전 123 · 가스안전공사 · 지자체 120), **전화 연결·누리집 열기**, 신고서+증거사진 **공유(문자·메일·메신저)** |
| 7. 지갑 | 5층 보수 내역(L1~L5), 산정 대기 표시, 현금 전환 신청 → 콘솔 결재 |
| 8. 프로필 | 등급 진행, 신뢰점수, 배지, 약관, **점검 기록 CSV 내보내기**, 권한 상태 확인, 데이터 초기화 |
| 9. 협회 콘솔 | **운영자 코드로만 진입**, KPI, 검증 큐(증거사진·메모·보고서 열람, 승인/반려+사유), 지역 히트맵, 정산 승인, **월간 리포트 CSV** |

공통: 안드로이드 **뒤로가기 버튼**, 오프라인 저장(상태 localStorage · 사진 IndexedDB), 상태바·노치·홈바 안전영역, 세로 고정, 앱 아이콘(에안이)·스플래시(에안이+협회 로고).

### 시범 코드
- 수료증 코드: `ESEA-3-0001`(김지킴·인증), `ESEA-3-0002`(이지킴), `ESEA-1-0001`(박지킴·시니어)
- 운영자 코드: `ESEA-ADMIN-01`

### 아직 시범(데모)인 부분 — 기획서 로드맵상 다음 단계
- **백엔드 미연결**: 회원 명부·케이스·검증 큐가 기기 안에서만 동작합니다. 2단계에서 `www/js/store.js`의 저장 지점을 Supabase(또는 Firebase)로 바꾸면 여러 지킴이·협회가 같은 데이터를 봅니다 (기획서 4.3 테이블 구조 그대로).
- **AI 판정**: 화면·흐름만 구현, 판정 값은 시연용입니다 (기획서 4.1 — 3단계에서 온디바이스 모델 도입).
- **지도**: OpenStreetMap 사용. 네이버/카카오 지도 API로 바꾸려면 `initMap()` 한 곳만 교체하면 됩니다.
- **시설 좌표·케이스·보수 금액**: `www/js/data.js`의 예시 데이터입니다.

## 2. 휴대폰에 설치하는 방법

### 방법 A — 가장 빠름: 웹앱(PWA)으로 설치 (안드로이드·아이폰 공통, 비용 0원)
1. 이 폴더를 GitHub 저장소에 올리면 `.github/workflows/pwa-pages.yml`이 **GitHub Pages**에 자동 배포합니다 (저장소 Settings › Pages › Source를 "GitHub Actions"로 지정).
2. 휴대폰에서 배포 주소 접속
   - 안드로이드 Chrome: 메뉴 › **홈 화면에 추가 / 앱 설치**
   - 아이폰 Safari: 공유 버튼 › **홈 화면에 추가**
3. 카메라·위치는 HTTPS 주소에서만 동작합니다 (GitHub Pages는 HTTPS).

### 방법 B — 안드로이드 설치 파일(APK)
**B-1. 클라우드 자동 빌드 (PC에 개발 도구 설치 불필요)**
1. 이 폴더를 GitHub 저장소(main 브랜치)에 올립니다.
2. 저장소 **Actions** 탭 › "Build apps" 실행 완료 후 **E-guardian-android** 아티팩트를 내려받으면 `app-debug.apk`가 들어 있습니다.
3. 휴대폰으로 APK를 옮겨 설치 (설정에서 "출처를 알 수 없는 앱 설치" 허용).

**B-2. PC에서 직접 빌드**
```bash
npm install
npm run android      # 라이브러리 복사 + 동기화 후 Android Studio가 열림 → ▶ Run
```
필요: Node.js 20 이상, Android Studio(JDK 21 포함).

### 방법 C — 아이폰 앱
아이폰 앱은 Apple 정책상 **Mac + Xcode**가 필요합니다.
```bash
npm install
npm run ios          # Xcode가 열림 → Signing & Capabilities에서 Team 선택 → 아이폰 연결 후 ▶ Run
```
- 무료 Apple ID로도 본인 아이폰에 7일간 설치·시험 가능, 여러 명 배포(TestFlight)·App Store 출시는 Apple Developer Program(연 99달러, 기획서 4.2) 필요.
- GitHub Actions의 iOS 작업은 서명 없이 **컴파일이 되는지 검증**하고 시뮬레이터용 빌드를 남깁니다.

### 스토어 출시 (기획서 3단계 이후)
- Google Play: Play Console 등록(25달러, 1회) → 서명 키를 GitHub Secrets(`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`)에 넣으면 Actions가 **AAB**를 함께 만듭니다.
- 데이터 안전 섹션 답변 근거: 위치(점검 증거·근접 안내, 앱 사용 중만), 사진(증거), 제3자 제공 없음 — 개인정보 처리방침 URL 필요.

## 3. 폴더 구조
```
www/                 화면 코드 (안드로이드·iOS·웹 공통)
  index.html         화면 9종 + 온보딩·동의
  css/app.css        디자인 (프로토타입 색·컴포넌트 계승)
  js/data.js         체크리스트 v1 · 시설 · 시드 케이스 · 신고 채널 · 시범 명부(해시)
  js/native.js       카메라·GPS·진동·공유·뒤로가기 (앱=Capacitor, 웹=브라우저 API)
  js/store.js        로컬 저장 (→ 2단계에서 Supabase로 교체할 지점)
  js/app.js          화면 동작
  manifest.webmanifest, sw.js   PWA 설치·오프라인
android/             안드로이드 Studio 프로젝트 (권한: 카메라·위치·진동)
ios/                 Xcode 프로젝트 (Swift Package Manager, 권한 안내 문구 한국어)
resources/           앱 아이콘·스플래시 원본 (npm run assets 로 재생성)
.github/workflows/   APK·iOS 자동 빌드, PWA 자동 배포
```
화면을 고친 뒤에는 `npx cap sync`로 android/ios에 반영합니다.

앱 식별자: `kr.esea.eguardian` (스토어 등록 전 협회 도메인에 맞게 변경 가능 — `capacitor.config.json`)
